# 🏫 OnClass — Sistema Integrado de Gestão de Abono de Faltas & Atestados

Plataforma full-stack desenvolvida para a automação, triagem e validação pedagógica de solicitações de abono de faltas, justificativas de ausência com atestados médicos e requerimentos de segunda chamada acadêmica.

---

## 📌 Visão Geral da Solução
